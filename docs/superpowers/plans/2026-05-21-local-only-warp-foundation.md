# Local-only Warp Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the downstream patch workflow, local-only verification harness, and packaging wrapper that make the aggressive local-only deletion work repeatable.

**Architecture:** This first implementation slice adds only maintenance infrastructure: patch export/application scripts, a static verifier, and a packaging wrapper. Product-code deletion is intentionally handled by follow-up plans after this harness exists, so each deletion domain can be validated and exported as a semantic patch commit.

**Tech Stack:** Bash, Git `format-patch`/`am`, ripgrep, Cargo, existing Warp packaging scripts.

---

## Scope split

The approved design spans several independent subsystems: auth, billing, cloud objects, team/workspace, managed secrets, telemetry/update/crash, AI routing, workspace dependency pruning, and packaging. A single implementation plan with exact code edits for all of those domains would be too broad and brittle.

This plan implements the foundation required before deleting those subsystems:

- `patches/local-only/` patch-set storage.
- `script/local-only/export-patches`.
- `script/local-only/apply-patches`.
- `script/local-only/verify` with a self-test and local-only static scans.
- `script/local-only/package`.
- `script/local-only/release-check`.

Follow-up plans should each cover one deletion domain from the approved design.

## File structure

- Create: `patches/local-only/README.md` — documents the patch-set format and sync workflow.
- Create: `patches/local-only/series` — ordered patch list consumed by `apply-patches`.
- Create: `script/local-only/lib.sh` — shared Bash helpers used by all local-only scripts.
- Create: `script/local-only/export-patches` — exports semantic downstream commits to patch files.
- Create: `script/local-only/apply-patches` — applies patch files in `series` order.
- Create: `script/local-only/verify` — runs self-tests, compile checks, and static no-cloud scans.
- Create: `script/local-only/package` — runs verification, then invokes the platform packaging flow.
- Create: `script/local-only/release-check` — prints and enforces the release smoke checklist.

# Local-only patch set

This directory stores the downstream patch stack for the local-only Warp fork.

The patch stack is generated from semantic commits on the local-only branch. It is used when syncing a fresh upstream `master` to the local-only fork.

## Files

- `series` lists patch files in application order.
- `*.patch` files are generated by `script/local-only/export-patches`.

## Export patches from a local-only branch

Run from the repository root on the local-only branch:

```bash
script/local-only/export-patches upstream/master
```

If `upstream/master` is not available, pass the base ref explicitly:

```bash
script/local-only/export-patches origin/master
```

## Apply patches to a fresh upstream branch

Create a branch from the upstream ref, then apply the patch series:

```bash
git fetch upstream
git checkout -b local-only-$(date +%Y%m%d) upstream/master
script/local-only/apply-patches patches/local-only
```

If a patch conflicts, Git stops at the failing patch. Resolve the conflict, stage the resolved files, and continue:

```bash
git am --continue
```

After all patches apply, run:

```bash
script/local-only/verify
script/local-only/package
```

## Patch policy

Each patch should represent one local-only domain, such as auth removal, billing removal, cloud object removal, or AI endpoint routing. Avoid combining unrelated domains in one patch.
```

#!/usr/bin/env bash

local_only_repo_root() {
  git rev-parse --show-toplevel
}

local_only_die() {
  echo "local-only: $*" >&2
  exit 1
}

local_only_require_cmd() {
  local cmd="$1"
  command -v "$cmd" >/dev/null 2>&1 || local_only_die "required command not found: $cmd"
}

local_only_require_clean_worktree() {
  local status
  status="$(git status --porcelain)"
  if [[ -n "$status" ]]; then
    echo "$status" >&2
    local_only_die "working tree must be clean"
  fi
}

local_only_default_base_ref() {
  if git rev-parse --verify upstream/master >/dev/null 2>&1; then
    echo "upstream/master"
  elif git rev-parse --verify origin/master >/dev/null 2>&1; then
    echo "origin/master"
  elif git rev-parse --verify master >/dev/null 2>&1; then
    echo "master"
  else
    local_only_die "could not find upstream/master, origin/master, or master"
  fi
}

local_only_patch_dir() {
  local root
  root="$(local_only_repo_root)"
  echo "$root/patches/local-only"
}

local_only_series_file() {
  local patch_dir="$1"
  echo "$patch_dir/series"
}

local_only_print_header() {
  local title="$1"
  echo
  echo "==> $title"
}
```

#!/usr/bin/env bash
set -euo pipefail

ROOT="$(git rev-parse --show-toplevel)"
# shellcheck source=script/local-only/lib.sh
source "$ROOT/script/local-only/lib.sh"

usage() {
  cat <<'USAGE'
Usage: script/local-only/export-patches [BASE_REF]

Exports commits from BASE_REF..HEAD to patches/local-only/*.patch and rewrites
patches/local-only/series. BASE_REF defaults to upstream/master, origin/master,
or master, whichever exists first.
USAGE
}

if [[ "${1:-}" == "-h" || "${1:-}" == "--help" ]]; then
  usage
  exit 0
fi

local_only_require_cmd git
local_only_require_clean_worktree

BASE_REF="${1:-$(local_only_default_base_ref)}"
PATCH_DIR="$(local_only_patch_dir)"
SERIES_FILE="$(local_only_series_file "$PATCH_DIR")"

if ! git rev-parse --verify "$BASE_REF" >/dev/null 2>&1; then
  local_only_die "base ref does not exist: $BASE_REF"
fi

local_only_print_header "Exporting local-only patches"
echo "Base ref: $BASE_REF"
echo "Patch dir: $PATCH_DIR"

mkdir -p "$PATCH_DIR"
rm -f "$PATCH_DIR"/*.patch "$SERIES_FILE"

PATCH_COUNT="$(git rev-list --count "$BASE_REF..HEAD")"
if [[ "$PATCH_COUNT" == "0" ]]; then
  : > "$SERIES_FILE"
  echo "No commits to export. Wrote empty series file."
  exit 0
fi

git format-patch \
  --output-directory "$PATCH_DIR" \
  "$BASE_REF..HEAD" \
  -- \
  . \
  ':(exclude)patches/local-only/*.patch' \
  ':(exclude)patches/local-only/series'

find "$PATCH_DIR" -maxdepth 1 -type f -name '*.patch' -exec basename {} \; | sort > "$SERIES_FILE"

echo "Exported patches:"
cat "$SERIES_FILE"
```

#!/usr/bin/env bash
set -euo pipefail

ROOT="$(git rev-parse --show-toplevel)"
# shellcheck source=script/local-only/lib.sh
source "$ROOT/script/local-only/lib.sh"

usage() {
  cat <<'USAGE'
Usage: script/local-only/apply-patches [PATCH_DIR]

Applies patches listed in PATCH_DIR/series using git am. PATCH_DIR defaults to
patches/local-only.
USAGE
}

if [[ "${1:-}" == "-h" || "${1:-}" == "--help" ]]; then
  usage
  exit 0
fi

local_only_require_cmd git
local_only_require_clean_worktree

PATCH_DIR="${1:-$(local_only_patch_dir)}"
if [[ "$PATCH_DIR" != /* ]]; then
  PATCH_DIR="$ROOT/$PATCH_DIR"
fi
SERIES_FILE="$(local_only_series_file "$PATCH_DIR")"

[[ -d "$PATCH_DIR" ]] || local_only_die "patch directory does not exist: $PATCH_DIR"
[[ -f "$SERIES_FILE" ]] || local_only_die "series file does not exist: $SERIES_FILE"

local_only_print_header "Applying local-only patches"
echo "Patch dir: $PATCH_DIR"

if [[ ! -s "$SERIES_FILE" ]]; then
  echo "Series file is empty; no patches to apply."
  exit 0
fi

while IFS= read -r patch_name; do
  [[ -z "$patch_name" ]] && continue
  [[ "$patch_name" == \#* ]] && continue
  patch_path="$PATCH_DIR/$patch_name"
  [[ -f "$patch_path" ]] || local_only_die "patch listed in series does not exist: $patch_path"
  echo "Applying $patch_name"
  git am "$patch_path"
done < "$SERIES_FILE"

echo "All local-only patches applied."
```

Write this exact file:

```bash
#!/usr/bin/env bash
set -euo pipefail

ROOT="$(git rev-parse --show-toplevel)"
# shellcheck source=script/local-only/lib.sh
source "$ROOT/script/local-only/lib.sh"

RUN_CARGO=true
RUN_STATIC=true
RUN_SELF_TEST=false

usage() {
  cat <<'USAGE'
Usage: script/local-only/verify [--self-test] [--static-only] [--skip-static] [--skip-cargo]

Runs local-only verification checks.

Options:
  --self-test     Validate the verifier against generated pass/fail fixtures.
  --static-only   Run static scans without cargo check.
  --skip-static   Run cargo check without static scans.
  --skip-cargo    Run static scans without cargo check.
USAGE
}

while (( "$#" )); do
  case "$1" in
    --self-test)
      RUN_SELF_TEST=true
      RUN_CARGO=false
      RUN_STATIC=false
      shift
      ;;
    --static-only)
      RUN_CARGO=false
      RUN_STATIC=true
      shift
      ;;
    --skip-static)
      RUN_STATIC=false
      shift
      ;;
    --skip-cargo)
      RUN_CARGO=false
      shift
      ;;
    -h|--help)
      usage
      exit 0
      ;;
    *)
      local_only_die "unknown argument: $1"
      ;;
  esac
done

local_only_require_cmd git
local_only_require_cmd rg

FORBIDDEN_REGEX='(app\.warp\.dev|api\.warp\.dev|graphql/v2|stripeBillingPortal|freeAvailableModels|GetRequestLimitInfo|GetAiOveragesForWorkspace|createAnonymousUser|create_anonymous_user|Rudder|rudder|Sentry|sentry|crash_reporting|crash reporting|remote config|feature flag fetch|warp_server_client|warp_graphql|firebase|managed_secrets|BillingMetadata|CustomerType|DelinquencyStatus)'
REQUIRED_REGEX='(api key|API key|ApiKey|base_url|Base URL|base URL|custom endpoint|custom_endpoint)'
SCAN_TARGETS=("app/src" "crates" "Cargo.toml" "app/Cargo.toml")

scan_forbidden() {
  local scan_root="$1"
  shift
  local -a targets=("$@")
  local -a existing_targets=()

  for target in "${targets[@]}"; do
    if [[ -e "$scan_root/$target" ]]; then
      existing_targets+=("$scan_root/$target")
    fi
  done

  if [[ "${#existing_targets[@]}" -eq 0 ]]; then
    echo "No scan targets exist under $scan_root"
    return 0
  fi

  if rg -n --hidden --glob '!target/**' --glob '!.git/**' --glob '!docs/superpowers/**' --glob '!patches/local-only/**' "$FORBIDDEN_REGEX" "${existing_targets[@]}"; then
    return 1
  fi

  return 0
}

scan_required_ai_config() {
  local scan_root="$1"
  if rg -n --hidden --glob '!target/**' --glob '!.git/**' "$REQUIRED_REGEX" "$scan_root/app/src" "$scan_root/crates/ai" >/dev/null 2>&1; then
    return 0
  fi
  return 1
}

run_self_test() {
  local_only_print_header "Running verifier self-test"
  local tmp
  tmp="$(mktemp -d)"
  mkdir -p "$tmp/app/src" "$tmp/crates/ai"

  cat > "$tmp/app/src/local.rs" <<'PASS_FIXTURE'
pub fn local_terminal_marker() -> &'static str {
    "local terminal"
}
PASS_FIXTURE

  cat > "$tmp/crates/ai/config.rs" <<'AI_FIXTURE'
pub struct LocalAiConfig {
    pub api_key: String,
    pub base_url: String,
}
AI_FIXTURE

  if ! scan_forbidden "$tmp" "app/src" "crates"; then
    rm -rf "$tmp"
    local_only_die "self-test pass fixture was reported as forbidden"
  fi

  cat > "$tmp/app/src/cloud.rs" <<'FAIL_FIXTURE'
pub const WARP_GRAPHQL: &str = "https://app.warp.dev/graphql/v2";
FAIL_FIXTURE

  if scan_forbidden "$tmp" "app/src" "crates"; then
    rm -rf "$tmp"
    local_only_die "self-test fail fixture was not reported as forbidden"
  fi

  if ! scan_required_ai_config "$tmp"; then
    rm -rf "$tmp"
    local_only_die "self-test AI config fixture was not detected"
  fi

  rm -rf "$tmp"
  echo "Verifier self-test passed."
}

if [[ "$RUN_SELF_TEST" == true ]]; then
  run_self_test
  exit 0
fi

if [[ "$RUN_CARGO" == true ]]; then
  local_only_print_header "Running cargo check for app"
  cargo check -p warp --bin warp-oss
fi

if [[ "$RUN_STATIC" == true ]]; then
  local_only_print_header "Scanning for forbidden cloud/account surfaces"
  if ! scan_forbidden "$ROOT" "${SCAN_TARGETS[@]}"; then
    local_only_die "forbidden cloud/account surfaces remain"
  fi

  local_only_print_header "Checking AI configuration surface"
  if ! scan_required_ai_config "$ROOT"; then
    local_only_die "could not find AI API key/Base URL configuration surface"
  fi
fi

echo "Local-only verification passed."
```

#!/usr/bin/env bash
set -euo pipefail

ROOT="$(git rev-parse --show-toplevel)"
# shellcheck source=script/local-only/lib.sh
source "$ROOT/script/local-only/lib.sh"

usage() {
  cat <<'USAGE'
Usage: script/local-only/package [--skip-verify] [--debug]

Runs local-only verification and then invokes the platform packaging script.

Environment:
  LOCAL_ONLY_VERIFY_ARGS  Extra arguments passed to script/local-only/verify.
USAGE
}

SKIP_VERIFY=false
DEBUG=false

while (( "$#" )); do
  case "$1" in
    --skip-verify)
      SKIP_VERIFY=true
      shift
      ;;
    --debug)
      DEBUG=true
      shift
      ;;
    -h|--help)
      usage
      exit 0
      ;;
    *)
      local_only_die "unknown argument: $1"
      ;;
  esac
done

cd "$ROOT"

if [[ "$SKIP_VERIFY" == false ]]; then
  local_only_print_header "Running local-only verification before packaging"
  VERIFY_ARGS=()
  if [[ -n "${LOCAL_ONLY_VERIFY_ARGS:-}" ]]; then
    read -r -a VERIFY_ARGS <<< "$LOCAL_ONLY_VERIFY_ARGS"
  fi
  script/local-only/verify "${VERIFY_ARGS[@]}"
fi

local_only_print_header "Packaging local-only desktop artifact"
case "$(uname -s)" in
  Darwin)
    if [[ "$DEBUG" == true ]]; then
      script/macos/bundle --nosign --nouniversal --debug -c local
    else
      script/macos/bundle --nosign --nouniversal -c local
    fi
    ;;
  Linux)
    if [[ "$DEBUG" == true ]]; then
      script/linux/bundle --debug -c local
    else
      script/linux/bundle -c local
    fi
    ;;
  MINGW*|MSYS*|CYGWIN*)
    if command -v pwsh >/dev/null 2>&1; then
      pwsh script/windows/bundle.ps1
    else
      local_only_die "Windows packaging requires pwsh"
    fi
    ;;
  *)
    local_only_die "unsupported packaging platform: $(uname -s)"
    ;;
esac
```
